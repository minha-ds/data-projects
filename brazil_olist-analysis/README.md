# Brazil Olist E-commerce Data Analysis

## Project Overview
Brazil Olist 이커머스 데이터를 분석하여 
고객 리뷰 데이터를 기반으로 배송 관련 문제를 파악하고 
배송 서비스 개선을 위한 인사이트를 도출한 프로젝트입니다. 

## Dataset
Kaggle Brazil Olist E-commerce Dataset

## Analysis Process 
1. 리뷰 데이터 전처리 및 텍스트 분석
2. 고객 리뷰 키워드 분석을 통한 주요 불만 요인 도출
3. 배송 관련 문제 발생 패턴 분석
4. 지역 기반 배송 문제 분석

## Key Findings
- 리뷰 키워드 워드클라우드
- 배송 관련 불만 키워드 분석
- 배송 문제 발생 빈도 분석
- 지역 기반 배송 문제 지도 시각화

## Business Insight
배송 문제 발생이 높은 지역을 중심으로 물류 프로세스를 개선하고  
배송 시간을 단축하는 전략이 고객 만족도 개선에 기여할 것으로 판단됩니다.
