# Instacart Customer Purchase Analysis

## Project Overview
Instacart 고객 주문 데이터를 분석하여 고객의 재구매 패턴과 상품 구매 행동을 분석한 프로젝트입니다.

## Dataset
Kaggle Instacart Market Basket Analysis Dataset

## Analysis
- 고객 재구매율 분석
- 주문 시간대별 구매 패턴 분석
- 상품 카테고리별 구매 비중 분석
- 자주 함께 구매되는 상품 분석

## Tools
Python  
Pandas  
Matplotlib / Seaborn
